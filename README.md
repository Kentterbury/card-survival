# 카드 서바이벌 (Card Survival)

하스스톤식 카드 운영에 줄(lane) 전투를 섞은 **1:1 턴제 HTML5 게임**입니다. 해골 군단과 싸우려고 **왕국이 고용한 용병대장**이 되어 오염된 숲과 던전, 그 아래 동굴의 여덟 지휘관을 쓰러뜨리는 이야기입니다. 브라우저에서 바로 돌아가며, Three.js로 3D 보드를 그리고 카드·HUD는 DOM으로 구성했습니다.

- 3챕터 8스테이지(1장 숲 3 · 2장 던전 3 · 3장 동굴 2), 스테이지마다 다른 지휘관(상대 영웅)과 1:1로 대결합니다. 숲에서는 늑대 떼(속도), 슬라임(분열), 해골 사냥꾼(불사·덫)이, 던전과 동굴에서는 해골 지휘관들이 기다립니다. 지휘관마다 전술과 전용 카드·지휘술이 있습니다.
- 양쪽 하수인은 턴이 끝날 때마다 한 칸씩 전진하고, 앞에 적이 있으면 공격합니다. 끝까지 막히지 않으면 상대 영웅을 때립니다.
- 손패·하수인·주문 구조는 하스스톤과 비슷하지만, 규칙과 용어, 카드 디자인은 독자적으로 만들었습니다. 마나는 **최대 20**(매 턴 +1, 남은 마나 이월 없음)이고, 첫 턴 마나(수비대장 2 ~ 비전술사 5)와 지휘술 비용은 영웅마다 다릅니다. 자세한 내용은 [docs/DESIGN.md](docs/DESIGN.md)를 보세요. 모든 카드의 현재 수치는 [docs/CARDS.md](docs/CARDS.md)(카드 현황), 스테이지별 지휘관과 적 카드는 [docs/MONSTERS.md](docs/MONSTERS.md)(몬스터 현황)에 있습니다(게임 데이터에서 `npm run docs`로 자동 생성).
- 런을 시작할 때 용병대장 4명(수비대장·비전술사·전쟁 족장·척후대장) 중 하나를 고릅니다. 영웅마다 생명력, 지휘술, 시작 덱이 다릅니다.
- 영웅마다 콘셉트에 맞는 **전용 카드**가 4장씩 있어, 보상·상인·탐색에서 그 영웅에게만 나옵니다.
- 스테이지를 클리어하면 카드 꾸러미(3장) 하나를 골라 덱에 추가하고(던전 런 방식), 야영지에서 휴식(회복)이나 정비(카드 제거)를 합니다.
- 진행은 스테이지 단위로 브라우저에 저장되어, 타이틀에서 이어할 수 있습니다.
- 스테이지를 이기면 금화를 받고(빨리 이길수록 많이), 챕터마다 한 번 찾아오는 왕국 보급관에게서 카드·카드 제거·회복 물약을 살 수 있습니다.
- 효과음과 배경음은 WebAudio로 실시간 합성합니다(오디오 파일 없음). 왼쪽 위 버튼으로 끌 수 있습니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 에 정적 파일 생성
npm test           # 규칙 엔진 테스트 + 봇 시뮬레이션
```

`?speed=4` 쿼리를 붙이면 모든 연출이 빨라집니다(테스트용).

## 휴대폰에서 플레이

GitHub Pages에 배포되면 `https://kentterbury.github.io/card-survival/` 에서 바로 플레이할 수 있습니다.

- 가로 화면 전용입니다(세로로 들면 돌려 달라는 안내가 나옵니다).
- 모든 조작은 **탭 → 탭**으로 됩니다. 카드를 탭하면 크게 들어 올려지고, 놓을 수 있는 칸이 초록색으로 표시됩니다.
- 브라우저 메뉴에서 **홈 화면에 추가**를 하면 앱처럼 전체 화면으로 실행됩니다(iPhone: Safari 공유 → 홈 화면에 추가 / Android: Chrome 메뉴 → 홈 화면에 추가).

## 조작

| 동작 | 방법 |
|---|---|
| 카드 사용 | 카드를 끌어다 놓기, 또는 카드 클릭(탭) 후 대상 클릭(탭) |
| 정보 보기 | 마우스를 올리거나 유닛을 탭 |
| 지휘술 | 왼쪽 아래 버튼(영웅마다 다름). 대상이 필요하면 이어서 대상 선택. 꾹 누르거나 마우스를 올리면 설명 |
| 상대 영웅 공격 | 피해 주문을 들고 오른쪽 위 초상화나 성문 앞 3D 영웅을 탭 |
| 취소 | 우클릭 / ESC |
| 턴 종료 | 오른쪽 버튼 / Space |
| 카드북 | 타이틀의 「카드북」 또는 왼쪽 위 책 아이콘. 전체 카드, 영웅별 필터, 검색, **최근 변경**(NEW/수정 표시) |
| 카메라 시점 | 왼쪽 위 카메라 아이콘. 기본 / 측면 전장 / 아이소메트릭 중 선택(카메라가 움직이며 전환, 설정 저장) |

## 구조

```
src/
  game/        규칙 엔진 (렌더링과 무관한 순수 TS — 테스트 대상)
    engine.ts    턴 진행, 줄 전투, 스테이지/보상 흐름, 이벤트 발행
    ai.ts        상대 영웅 AI (테스트 봇도 사용)
    cards.ts     카드 정의와 효과 (양쪽 공용, 시전자 기준으로 작성)
    heroes.ts    플레이어 영웅·지휘술·시작 덱
    stages.ts    스테이지별 상대 영웅·덱·지휘술
    rewards.ts   보상 꾸러미
    shop.ts      금화 보상과 상인 물품
    changelog.ts 카드 변경 기록 (카드북 「최근 변경」 탭)
  audio/       WebAudio 효과음·배경음 합성
  render/      Three.js (보드, 유닛, 이펙트, 초상화 렌더링)
  ui/          카드 DOM, 아이콘, 카드북
  sim/bot.ts   밸런스 확인용 자동 플레이(플레이어 쪽에 ai.ts 사용)
  main.ts      게임 ↔ 3D ↔ UI 연결, 입력, 이벤트 연출 재생
tests/         vitest
tools/optimize-assets.mjs   에셋 최적화 스크립트
tools/build-spell-art.mjs   주문 카드 그림(game-icons.net) 생성
tools/optimize-synty.mjs    Synty 변환본 압축 + manifest 생성
```

규칙 엔진은 행동마다 `GameEvent[]`를 반환하고, `main.ts`가 이 이벤트를 순서대로 연출한 뒤 최종 상태와 화면을 동기화합니다. 규칙을 바꿀 때 렌더링 코드를 건드릴 필요가 없습니다.

## 에셋

3D 모델과 애니메이션은 모두 [KayKit](https://kaylousberg.com)의 **CC0(퍼블릭 도메인)** 팩입니다. 주문 카드 그림은 [game-icons.net](https://game-icons.net) 아이콘(CC BY 3.0, 출처 표시 필요)을 주문마다 하나씩 골라 씁니다(`tools/build-spell-art.mjs`). 타이틀 화면에 출처를 적어 두었습니다. 공개 저장소에 올려도 문제가 없습니다. 출처는 [public/assets/LICENSES.md](public/assets/LICENSES.md)에 정리했습니다.

- Adventurers(아군 하수인), Skeletons(몬스터), Dungeon Remastered(배경)
- 모든 캐릭터가 같은 리그를 쓰기 때문에, 애니메이션은 공용 라이브러리 파일 두 개로 분리했습니다. 원본 37MB를 3MB로 줄였습니다.

에셋을 다시 만들려면 KayKit 저장소들을 한 폴더에 받은 뒤 다음을 실행합니다.

```bash
node tools/optimize-assets.mjs <KayKit 저장소들이 있는 폴더>
```

### Synty 세트 (선택)

`public/synty/manifest.json`이 있으면 KayKit 대신 Synty POLYGON 모델(던전, 판타지 왕국, 기사, 판타지 캐릭터)을 자동으로 씁니다. 애니메이션은 DoubleL 팩을 리타깃해서 씁니다.

- 유료 에셋이라 이 공개 저장소에는 넣지 않습니다.
- 변환본은 비공개 저장소 `Kentterbury/cardproject`에 있고, Pages 배포 때 `ASSET_TOKEN` 시크릿으로 받아 옵니다.
- 토큰이 없으면 KayKit으로 배포됩니다.

설정 방법과 변환 파이프라인은 [docs/SYNTY.md](docs/SYNTY.md)에 있습니다. 손에 든 무기 위치는 무기 위치 편집기(`grip.html`, 타이틀 화면 아래 링크)로 고칠 수 있습니다.
