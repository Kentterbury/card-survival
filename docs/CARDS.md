## 하수인 비용 곡선

가치 = 공격력 + 체력(공격력 0이면 ×0.7) + 키워드 점수 + 효과 점수, 기준 = 비용 + 2. 희귀 +1, 영웅 등급 +2, 영웅 전용 +1까지 허용하고 그 범위에서 ±1 안이어야 합니다(`src/game/curve.ts`). 표의 「곡선」은 허용치를 뺀 차이입니다.
