# 게임 디자인 문서

## 콘셉트

해골 군단의 지휘관들과 벌이는 **1:1 카드 대결**. 양쪽 모두 마나·손패·덱·지휘술을 가지고, 하수인을 보내 상대 진영으로 밀고 들어가거나 주문으로 상대 영웅을 직접 노린다.

**하스스톤의 손패·마나·주문 운영** + **줄(lane)을 따라 전진하는 하수인** + **던전 런식 덱 성장**.

## 보드

```
            [ 상대 영웅 ]
 5행  [적진] [적진] [적진] [적진] [적진]   ← 상대가 소환하는 줄
 4행  [   ] [   ] [   ] [   ] [   ]
 ...
 1행  [   ] [   ] [   ] [   ] [   ]
 0행  [내진] [내진] [내진] [내진] [내진]   ← 내가 소환하는 줄
            [ 내 영웅 ]
```

- 5줄 × 6행. 나는 0행, 상대는 5행에 하수인을 소환한다(빈 칸만 가능).
- **턴이 끝날 때 그 턴 주인의 하수인이 모두 행동**한다(앞에 있는 하수인부터).
  1. 사거리 안, 자기 줄 앞쪽에 적이 있으면 → 첫 번째 적을 공격
  2. 앞에 아무도 없이 상대 끝에 닿았으면 → **상대 영웅을 공격**
  3. 둘 다 아니면 → 이동력만큼 전진(막히면 멈춤)
- 근접 공격(바로 앞 칸)은 반격을 받는다. 사격(2칸 이상)은 반격을 받지 않는다.
- **돌파**: 근접 공격으로 적을 처치하면 공격한 하수인이 그 빈칸으로 한 칸 들어간다(이동력 0인 하수인 제외). 밀쳐내기로 비운 칸에는 들어가지 않는다. 1/1 졸개를 계속 깔아 줄을 막는 교착을 풀기 위한 규칙이다.
- **사격**: 사거리 3. 아군 너머로도 쏜다. 적이 없고 상대 영웅이 사거리 안이면 영웅을 쏜다.
- 소환된 턴에는 행동하지 않는다(**기습**은 예외). 공격력 0인 하수인은 자리를 지킨다.

## 승패

- 상대 영웅의 생명력을 0으로 만들면 스테이지 승리 → 보상 선택.
- 내 영웅의 생명력이 0이 되면 사망(런 종료). 내 생명력은 스테이지를 넘어 유지되며, 자동 회복은 없다. 대신 스테이지 사이 **야영지**에서 회복할 수 있다.

## 턴 구조 (양쪽 동일)

1. **턴 시작**: 최대 마나 +1(최대 10), 마나 회복, 카드 1장 드로우
2. **행동**: 카드 사용, 지휘술(2마나, 턴당 1회)
3. **턴 종료**: 남은 마나 중 **최대 1을 다음 턴으로 이월**, "턴 종료 시" 효과, **하수인 행동**

나는 선공이고 손패 3장(+첫 드로우)으로 시작한다. 덱이 바닥나면 버린 카드 더미를 섞어 다시 쓴다.

- **내 지휘술**: 고른 영웅에 따라 다름(아래 표)
- **상대 지휘술**: 스테이지마다 다름(해골 졸개 소환 또는 피해 1)

## 영웅 선택

런을 시작할 때 영웅을 고른다. 영웅마다 생명력, 지휘술, 시작 덱(10장)이 다르다.

| 영웅 | 생명력 | 지휘술 (2마나) | 시작 덱 성향 |
|---|---|---|---|
| 수비대장 | 32 | 지휘의 번개: 적 하나(영웅 포함)에게 피해 1 | 기본 하수인 + 화염탄·충격파·서리 고리·벼락 |
| 비전술사 | 22 | 비전 통찰: 카드 1장 드로우 | 주문 위주, 전쟁 서고·피의 계약으로 손패 확보 |
| 전쟁 족장 | 32 | 돌격 명령: 아군 하수인 하나에게 +1/+1, 한 칸 전진 | 방진병 2장·싸움꾼·광전사·전쟁 북 — 하수인으로 밀어붙임 |

## 야영지와 저장

- 보상 꾸러미를 고른 뒤 야영지에서 하나를 고른다.
  - **휴식**: 생명력 12 회복(최대치까지)
  - **정비**: 덱에서 카드 1장 제거(덱은 최소 5장 유지)
- 진행은 스테이지 단위로 브라우저(localStorage)에 저장된다. 스테이지 시작과 보상 선택 직후에 저장되며, 타이틀 화면의 **이어하기**로 마지막 스테이지 시작부터 다시 한다. 런이 끝나면(승리/사망) 저장이 지워진다.

## 상대(AI)

상대는 스테이지마다 정해진 덱(15장 안팎)으로 플레이한다. 매 턴 쓸 수 있는 카드를 모두 점수화해서 가장 좋은 것부터 낸다.
- 하수인은 가장 위협받는 줄에 낸다.
- 피해 주문은 처치할 수 있는 하수인이나 마무리 가능한 영웅을 노린다.
- 광역 주문은 맞힐 적이 둘 이상일 때만 쓴다.

같은 AI가 테스트에서 플레이어 쪽을 대신 플레이한다.

## 하스스톤과 다른 점 (저작권/상표 회피 + 장르 차이)

게임 규칙(메커니즘)은 저작권 보호 대상이 아니지만, 고유 명칭이나 아트, 카드 프레임 같은 표현은 보호 대상이다. 그래서 아래처럼 따로 만들었다.

| 항목 | 하스스톤 | 카드 서바이벌 |
|---|---|---|
| 보드 | 하수인 7칸 일렬 | 5줄 × 6행 격자, 하수인이 전진 |
| 전투 | 원하는 대상을 골라 공격 | 자동: 자기 줄 앞의 적, 없으면 전진 → 상대 영웅 |
| 마나 | 매 턴 초기화 | 1까지 다음 턴으로 이월 |
| 덱 소진 | 피로 피해 | 버린 카드를 섞어 재사용 |
| 키워드 | 도발/돌진/천상의 보호막/전투의 함성/죽음의 메아리 | 사격/기습/보호막/등장 시/파괴 시/빙결 |
| 카드 프레임 | 타원형 아트, 물방울 체력 | 아치형 아트, 육각 비용, 독자 프레임(CSS로 직접 제작) |
| 아트 | 블리자드 일러스트 | KayKit CC0 3D 모델을 실시간 렌더링한 초상화 |

블리자드의 카드명, 아트, 사운드, UI 그래픽은 하나도 쓰지 않았다.

## 키워드

| 키워드 | 효과 |
|---|---|
| 사격 | 자기 줄 앞쪽 3칸 안의 첫 적을 쏜다(아군 너머로도). 반격을 받지 않는다 |
| 기습 | 소환된 턴에도 바로 행동한다 |
| 보호막 | 처음 받는 피해를 무시한다 |
| 질주 | 매 턴 2칸씩 전진한다 |
| 고정 | 전진하지 않는다(공격력 0인 하수인도 자동으로 고정) |
| 넉백 | 공격한 적이 살아남으면 1칸 뒤로 밀어낸다 |
| 관통 | 대상 바로 뒤 칸의 적도 맞힌다. 뒤가 끝줄 밖이면 적 영웅이 맞는다 |
| 비행 | 하수인을 넘어 날아서 전진하고 적 영웅만 공격한다. 근접 공격으로는 맞지 않는다 |
| 대열 | 양옆 줄 같은 행에 아군이 있으면 공격력 +2 |
| 흡혈 | 준 피해만큼 내 영웅을 회복한다(반격 피해 포함) |
| 불사 | 처음 죽을 때 생명력 1로 되살아난다 |
| 휩쓸기 | 하수인을 공격할 때 양옆 줄 같은 행의 적도 공격한다 |
| 가시 | 근접 공격을 받으면 공격자에게 피해 2 |
| 엄호 | 같은 줄 다른 아군 대신 적의 사격을 맞는다(사거리 안일 때). 그 아군은 적의 대상 지정 주문에 지정되지 않는다 |
| 재생 | 자기 턴 시작 시 생명력을 모두 회복한다 |
| 분노 | 피해를 받고 살아남을 때마다 공격력 +1 |
| 선봉 | 아군 중 가장 앞(동률 포함)에 있으면 공격력 +2 |
| 등장 시 / 파괴 시 | 소환될 때 / 죽을 때 발동 |
| 빙결 | 다음 행동 1번을 건너뛴다 |

## 유틸리티 카드

| 카드 | 비용 | 효과 |
|---|---|---|
| 피의 계약 | 0 | 내 영웅 피해 3, 카드 2장 뽑기 |
| 전술 서고 | 1 | 탐색: 주문 카드 |
| 증원 요청 | 2 | 탐색: 하수인 카드(비용 -1) |
| 작전 변경 | 1 | 손패를 모두 버리고 같은 수만큼 뽑기 |
| 재활용 | 2 | 버린 카드 더미에서 무작위 2장 회수 |
| 봉인의 사슬 | 2 | 상대 손패 무작위 2장 봉인, 카드 1장 뽑기 |
| 소매치기 | 2 | 상대 손패에서 무작위 1장 빼앗기(빼앗은 적 카드도 사용 가능) |
| 도굴 | 1 | 상대 덱 맨 위 카드를 내 손으로 |
| 망각의 저주 | 1 | 상대의 다음 드로우 봉쇄, 카드 1장 뽑기 |
| 거울상 | 2 | 아군 하수인 카드를 복사(비용 -1) |
| 보급 마차 | 3 | 손패 모든 카드 비용 -1, 카드 1장 뽑기 |
| (적) 봉인의 저주 | 2 | 내 손패 1장 봉인 + 내 영웅 피해 1 |
| (적) 망자의 지혜 | 2 | 카드 2장 뽑기 |

- **탐색**: 무작위 카드 3장 중 하나를 골라 손으로 가져온다(하스스톤의 '발견'과 같은 메커니즘, 이름만 다름).
- **봉인**: 봉인된 카드는 그 주인의 다음 턴 동안 낼 수 없고, 그 턴이 끝나면 풀린다.
- 손패의 비용이 바뀐 카드는 비용 보석 색으로 표시한다(싸지면 초록, 비싸지면 빨강).

보상 꾸러미 추가: 학자의 서재, 도둑 길드(1등급), 병참, 저주술사(2등급).

## UI 메모

- 카드 대상 지정은 3D 모델 모양이 아니라 **바닥 타일 기준**이다. 마지막 줄 너머(성문 앞)는 적 영웅 칸이고, 적 영웅을 지정하면 발밑 원판이 켜진다.
- 오른쪽 세로 목록에 양쪽이 최근 낸 카드 6장이 표시된다(마우스 올리기/탭으로 확인).
- 지휘술 버튼은 마우스를 올리거나 휴대폰에서 꾹 누르면 설명이 뜬다.

| 방어 | 얼음 감옥 | 1 | 적 하수인 하나 빙결 + 2칸 밀어내기 |
| 방어 | 전장 신관 (1/4) | 3 | 턴 종료 시 내 영웅과 아군 모두 2 회복 |
| 유틸 | 마나 물약 | 0 | 이번 턴 마나 +2 |
| 방어 | 수호의 축복 | 3 | 아군 모두에게 보호막 |

## 보상

스테이지를 클리어하면 테마별 3장짜리 꾸러미 3개 중 하나를 고른다. 진행할수록 높은 등급의 꾸러미가 나온다(2스테이지 이후 2등급, 3스테이지 이후 3등급).

## 밸런스

`npm test`에 포함된 봇 시뮬레이션(상대와 같은 AI로 플레이어 쪽을 자동 플레이)으로 확인한다. 영웅별 봇 최종 승리율은 수비대장 약 40%, 비전술사 약 53%, 전쟁 족장 약 53%이고, 스테이지당 평균 15~20턴 걸린다. 3스테이지(서고의 주술사)가 가장 어렵다. 봇은 상대 영웅을 적극적으로 노리지 않으므로 사람이 하면 더 빨리 끝난다.
