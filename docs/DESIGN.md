# 게임 디자인 문서

## 콘셉트

무덤에서 깨어난 해골 군단이 성채로 밀려온다. 플레이어는 수비대장이 되어 카드로 하수인을 배치하고 주문을 외워 방어선을 지킨다.

**하스스톤의 손패·마나·하수인 운영** + **디펜스의 줄(lane)과 접근하는 적** + **던전 런식 덱 성장**.

## 보드

```
 줄:    0     1     2     3     4
 6행  [   ] [   ] [ S ] [   ] [   ]   ← 성문(스폰)
 5행  [   ] [   ] [   ] [   ] [   ]
 ...
 1행  [   ] [ M ] [   ] [   ] [   ]   ← 방어선 바로 앞
 ───────────────────────────────────  방어선
 0행  [ 하 ] [ 하 ] [   ] [ 하 ] [   ]   ← 하수인 슬롯
                  (영웅)
```

- 몬스터는 6행에서 나타나 매 적 턴 `이동력`만큼 앞으로 온다. 같은 줄의 앞 칸이 막혀 있으면 멈춘다.
- 몬스터가 `사거리` 안(행 번호 ≤ 사거리)에 들어오면 이동 대신 공격한다.
  - 그 줄의 슬롯에 하수인이 있으면 하수인을, 없으면 **영웅**을 공격한다.
  - 근접(1행) 공격은 하수인의 반격을 받는다.

## 턴 구조

1. **내 턴 시작**: 최대 마나 +1(최대 10), 마나 회복, 카드 1장 드로우, 하수인 공격권 회복
2. **행동**: 카드 사용 / 하수인 공격 / 영웅 능력(2마나, 몬스터에게 1 피해, 턴당 1회)
3. **턴 종료**: 남은 마나 중 **최대 1을 다음 턴으로 이월**, "턴 종료 시" 효과 발동
4. **적 턴**: 앞줄 몬스터부터 순서대로 이동하거나 공격 → 스크립트된 웨이브 등장

스테이지 시작 시 손패는 3장(+첫 턴 드로우 1장)이고 마나는 1부터 다시 시작한다. 덱이 바닥나면 버린 카드 더미를 섞어 다시 덱으로 만든다(피로 피해 없음).

## 하스스톤과 다른 점 (저작권/상표 회피 + 장르 차이)

게임 규칙(메커니즘)은 저작권 보호 대상이 아니지만, 고유 명칭이나 아트, 카드 프레임 같은 표현은 보호 대상이다. 그래서 아래처럼 따로 만들었다.

| 항목 | 하스스톤 | 카드 서바이벌 |
|---|---|---|
| 상대 | 다른 영웅 | 다가오는 몬스터 웨이브(PvE 디펜스) |
| 보드 | 하수인 7칸 일렬 | 5줄 × 7행 격자, 위치가 중요 |
| 공격 대상 | 아무 하수인/영웅 | 근접: 맨 앞줄(자기 줄 ±1), 사격: 자기 줄 전체 |
| 마나 | 매 턴 초기화 | 1까지 다음 턴으로 이월 |
| 덱 소진 | 피로 피해 | 버린 카드를 섞어 재사용 |
| 키워드 | 도발/돌진/천상의 보호막/전투의 함성/죽음의 메아리 | 사격/기습/보호막/등장 시/파괴 시/빙결 |
| 카드 프레임 | 타원형 아트, 물방울 체력 | 아치형 아트, 육각 비용, 독자 프레임(CSS로 직접 제작) |
| 아트 | 블리자드 일러스트 | KayKit CC0 3D 모델을 실시간 렌더링한 초상화 |

블리자드의 카드명, 아트, 사운드, UI 그래픽은 하나도 쓰지 않았다.

## 키워드

- **사격**: 같은 줄의 몬스터라면 거리와 상관없이 공격하고, 반격을 받지 않는다.
- **기습**: 소환된 턴에 바로 공격할 수 있다.
- **보호막**: 처음 받는 피해를 무시한다.
- **등장 시 / 파괴 시**: 소환될 때 / 죽을 때 발동한다.
- **빙결**: 다음 적 턴에 행동하지 못한다.

## 스테이지

| # | 이름 | 특징 |
|---|---|---|
| 1 | 무너진 성문 | 튜토리얼급. 졸개 위주 |
| 2 | 횃불의 회랑 | 2칸씩 오는 추적자 |
| 3 | 주술사의 서고 | 3칸 밖에서 공격하는 주술사, 보호막 수호병 |
| 4 | 뼈의 납골당 | 뼈 거인(6/14) |
| 5 | 군주의 왕좌 | 보스: 해골 군주(5/45, 매 턴 졸개 소환) |

스테이지 사이에 생명력 10을 회복한다. 생명력은 스테이지를 넘어도 유지된다.

## 보상

스테이지를 클리어하면 테마별 3장짜리 꾸러미 3개 중 하나를 고른다. 진행할수록 높은 등급의 꾸러미가 나온다(2스테이지 이후 2등급, 3스테이지 이후 3등급).

## 밸런스

`npm test`에 포함된 봇 시뮬레이션(욕심쟁이 자동 플레이)으로 확인한다. 현재 봇 승률은 약 40%다. 1~2스테이지는 거의 지지 않고, 4~5스테이지가 벽이다. 사람이 하면 봇보다 잘하므로 실제 체감 난이도는 이보다 쉽다.
